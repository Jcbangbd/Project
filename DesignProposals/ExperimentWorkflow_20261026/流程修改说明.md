# 实验流程调整（2026-10-26）

已按用户确认，把“设置参数”理解为算法参数，前置到算法选择之前。当前仿真决策实验链路调整为：

登录 → 选择任务 → 实验介绍 → 查看算例 → 设置算法参数 → 选择算法及原因 → 确认并进入实验 → 算法计算及设备作业 → 实验结束 → 开始答题 → 提交全部答题结果 → 返回实验介绍。

登录、任务选择、实验介绍的既有页面及学习模式未重做；本轮以当前接入的卸船仿真决策链路进行完整验证，未新增其他作业类型的算法或设备脚本。

## 各阶段的行为

| 阶段 | 实际行为 |
| --- | --- |
| 查看算例 | 原“进入答题”按钮改为“设置参数”，关闭算例页后打开参数页，不再提前答题。 |
| 设置算法参数 | 可分别编辑GA、PSO、ALNS的参数，切换标签会保留各自有效配置；未修改项使用原默认值。默认显示GA的参数不代表选择GA。非法参数不能继续。 |
| 保存参数 | 只保存本轮配置，然后进入算法介绍与选择页，不启动任何求解器、不加载三维实验。 |
| 选择算法 | 学生主动选择一种算法及其原因。确认后只取该算法之前保存的参数，进入三维场景并运行这一个算法，不按顺序执行三个算法。 |
| 算法完成 | 校验调度方案并调用原设备脚本开始作业，不再打开原先挡在实验前的调度结果核对页。 |
| 实验结束 | 必须同时满足本轮任务已全部完成、仿真时钟达到最后任务及设备运动结束时间、运动队列真正为空。算法计算完成不能代替实验结束。 |
| 开始答题 | 显示独立的原生“实验已结束”弹窗，点击“开始答题”才打开答题页面；未结束不能提前进入。 |
| 答题阶段 | 保留原第1至8题；八题后点击“继续结果核对”，完成原有Cmax、RMG任务数、共享区任务数及完整性核对。这些均属于实验后答题，不再位于实验前。 |
| 最终提交 | 沿用原评分与保存/服务器网关入口，全部答题完成后统一保存，然后自动返回原五流程实验介绍页，不重新启动实验。 |

## 结束检测与防串流程

- TaskManager仅新增只读的任务进度、导入版本及运动结束时间信息，不改变任务推进、岸桥分配或设备运动。
- 导入版本防止误把上一轮已完成任务当成本轮任务。
- 运动结束时间在任务导入时读取，覆盖最后一段已出队但仍在执行的运动。
- 使用旧队列现有 `IsEmpty` 标记，而不是依赖其计数恰好为0；旧实现最后出队后可能出现-1，本轮未修改队列实现。
- 返回介绍或切换实验会取消旧结束监控、关闭旧弹窗；开始运行后不能再次从算法入口触发同轮求解。
- 固定岸桥关系保持：A35→1010、A36→1011、A37→1012、A40→1013。
