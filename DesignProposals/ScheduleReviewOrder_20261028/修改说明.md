# 调度结果核对顺序修正（2026-10-28）

根据本次要求，修正此前把调度核对放到实验后八题之后的做法。当前流程为：

登录 → 选择任务 → 实验介绍 → 查看算例 → 设置算法参数 → 选择算法 → 执行算法 → 核对调度结果 → 提交核对并开始三维调度 → 实验结束 → 原8题 → 提交答题并返回实验介绍。

## 本次调整

- 算法成功后立即打开原“调度结果核对与提交”页面，此时不启动设备脚本，也不启动实验结束监控，三维画面保持锁定。
- 提交可解析的核对内容后，按原评分规则记录第16项，关闭核对页，再启动本次调度序列的原设备脚本。
- 未完整填写时仍停留在核对页；重复提交不重复创建任务。
- 实验结束后仍进行原8题，结束页按钮改为“提交答题并返回实验介绍”，不再重复进入调度核对页。
- 核对提交时仅在评分会话中记录本项；总成绩在实验结束后的8题完成时统一保存，并沿用原服务器网关条件，避免提前保存未答完的成绩。
- 参数前置、单次所选算法执行、评分规则、设备运动及固定岸桥对应关系均保留。

## 验证

在既有隔离工程使用真实43条卸船算例和一次本地遗传算法运行验证：

1. 算法成功即显示核对页，设备脚本、任务监控均未启动，场景仍锁定。
2. 不完整输入不能进入三维调度。
3. 提交核对后才实际导入43条设备任务；重复提交不增加任务。
4. 真实设备任务与最后运动完成后才开放8题。
5. 八题后直接保存并返回实验介绍，不再弹核对页。
6. 核对阶段不生成提前总成绩；最终只保存一份JSON，包含核对得分、全部8题答案、逐项分数与总分。
